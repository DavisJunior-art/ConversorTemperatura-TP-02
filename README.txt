PROJETO CONVERSOR DE TEMPERATURA - ANDROID STUDIO

Projeto Android nativo em Kotlin para converter Celsius em Fahrenheit.

Como abrir:
1. Abra o Android Studio.
2. Escolha Open.
3. Selecione a pasta android-temperature-converter.
4. Aguarde a sincronizacao do Gradle.
5. Inicie um emulador e clique em Run.

Formula usada: Fahrenheit = (Celsius x 9 / 5) + 32.
